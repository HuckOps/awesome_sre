## 本书特色

- **全真环境**：所有章节命令均在 Debian 13 实测环境中实际执行，输出逐字收录
- **鸟哥风格**：每个命令讲透语法、逐参数解释、附带常见错误解读
- **配套练习**：每章末尾有练习题，帮助巩固知识点
- **综合实战**：每卷末章为真实场景的端到端部署与加固

## 演示环境

```
平台：InstaBox 云电脑（instabox.sh）
系统：Debian 13（trixie），amd64
配置：4 vCPU / 8 GiB 内存，持久盘 20 GiB 挂载 /data，系统盘 16 GiB
登录：instabox ssh book（默认 root 身份）
```
