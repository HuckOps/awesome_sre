# 第 17 章 搭建实验环境：VMware + Ubuntu 本地虚拟机

> 第 1 章用 InstaBox 云电脑做实验环境，如果你本机条件允许，也可以在本地装虚拟机。本章演示如何用 **VMware Workstation Player** + **Ubuntu** 搭一台本地 Linux 实验机，所有命令同样可在此机器上验证。

## 17.1 方案对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| InstaBox 云电脑 | 零配置、不占本机资源、坏了即删即重建 | 需要网络、有免费额度限制 | 快速上手、本机配置较低 |
| VMware + Ubuntu | 离线可用、资源完全本地控制、可反复快照 | 需下载数 GB 镜像、占本机内存/磁盘 | 本机配置较高、需长期离线实验 |

## 17.2 准备工作

### 下载 VMware Workstation Player

1. 访问 VMware 官网，下载 **VMware Workstation Player**（免费供个人非商业用途）。
2. 下载器会先下载一个小型安装引导器，运行后联网获取完整安装包。
3. **重要：安装时不要选择默认的 C 盘路径。** 自定义安装路径，改为 D 盘或其他非系统盘目录，例如 `D:\VMware`。

### 下载 Ubuntu 镜像

1. 访问 Ubuntu 官网（`ubuntu.com/download/desktop`），下载 **Ubuntu 24.04 LTS** 的 64-bit ISO 镜像（约 5 GB）。
2. 将 ISO 文件保存到非 C 盘目录，例如 `D:\ISO\ubuntu-24.04-desktop-amd64.iso`。

## 17.3 安装 VMware Workstation Player

1. 双击下载的安装引导器，等待完整安装包下载完成。
2. 在安装向导中：
   - 接受许可协议。
   - **自定义安装路径**：选择 D 盘或其他非 C 盘目录（遵守“不安装到 C 盘”要求）。
   - 根据提示完成安装，如有重启提示，重启电脑。
3. 安装完成后启动 VMware Workstation Player，首次运行会要求输入许可证密钥，选择 **“免费用于个人非商业用途”** 即可。

## 17.4 创建 Ubuntu 虚拟机

1. 点击 **“创建新虚拟机”**。
2. 选择 **“典型”**（推荐）或 **“自定义”**。初学者选“典型”。
3. 选择安装介质：**“稍后安装操作系统”**（手动指定 ISO 更稳妥）。
4. 客户机操作系统：选择 **Linux**，版本选择 **Ubuntu 64-bit**。
5. 虚拟机名称：填 `book`（或你喜欢的名字）。
6. **位置**：选择 D 盘或其他非 C 盘目录，例如 `D:\VMs\book`。**不要放在 C 盘。**
7. 固件类型：保持默认 BIOS。
8. 磁盘容量：建议 **40 GB 或以上**，选择 **“将虚拟磁盘拆分为多个文件”**（便于迁移和备份）。
9. 点击 **“完成”** 后，虚拟机会列在左侧库中，但尚未启动。

## 17.5 启动并安装 Ubuntu

1. 选中 `book` 虚拟机，点击 **“编辑虚拟机设置”**。
2. 在 **CD/DVD (SATA)** 设置中，选择 **“使用 ISO 映像文件”**，浏览并指向你下载的 `ubuntu-24.04-desktop-amd64.iso`。
3. 确认 **“连接时启动”** 已勾选，点击 **“确定”**。
4. 点击 **“开启此虚拟机”**，Ubuntu 安装程序会从 ISO 启动。
5. 按安装向导操作：
   - 语言选择中文。
   - 键盘布局保持默认。
   - 安装类型选择 **“擦除磁盘并安装 Ubuntu”**（这是虚拟机内部的虚拟磁盘，不会影响你本机数据）。
   - 设置用户名和密码，记住它们，后面 SSH 和 sudo 都要用。
   - **不要勾选**“登录时要求密码”建议按实际习惯，实验机可选无密码自动登录方便调试。
6. 安装过程约需 15–30 分钟，完成后点击 **“立即重启”**。
7. 重启后，在 VMware 菜单栏选择 **“虚拟机” → “可移动设备” → “CD/DVD” → “断开连接”**，避免再次从 ISO 启动。

## 17.6 安装 VMware Tools（可选但推荐）

VMware Tools 可改善显示分辨率、剪贴板共享、文件拖拽等体验。

1. Ubuntu 启动后登录桌面。
2. 在 VMware 菜单栏选择 **“虚拟机” → “安装 VMware Tools”**。
3. 系统会挂载一个虚拟光盘，打开终端运行：
   ```bash
   cd /media/$USER/VMware\ Tools
   tar xzvf VMwareTools-*.tar.gz
   cd vmware-tools-distrib
   sudo ./vmware-install.pl -d
   ```
4. 安装完成后重启虚拟机。

## 17.7 验证环境

在 Ubuntu 终端中运行以下验货命令：

```bash
uname -a          # 查看内核版本
nproc             # 查看 CPU 核心数
free -h           # 查看内存
df -h /           # 查看根分区空间
ip addr           # 查看虚拟机 IP（桥接或 NAT 模式下）
```

如果能正常输出，说明 VMware + Ubuntu 实验环境已就绪，后续章节的所有命令都可在此机器上执行。

## 17.8 常见问题

| 问题 | 解决办法 |
|------|----------|
| 虚拟机无法启动，提示 VT-x/AMD-V 未启用 | 重启电脑进入 BIOS，开启虚拟化技术（Intel VT-x 或 AMD-V） |
| 安装卡在“准备安装” | 检查 ISO 文件是否完整，可重新下载 |
| 分辨率过小、无法全屏 | 安装 VMware Tools 后重启 |
| 想把虚拟机移到另一块盘 | 直接复制虚拟机文件夹（如 `D:\VMs\book`）到新位置，在 VMware 中移除后重新添加即可 |
