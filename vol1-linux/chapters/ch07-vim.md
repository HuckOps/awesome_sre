# 第 7 章 vim 编辑器

> 前面几章我们操作的对象都是文件本身：建、删、拷、改权。但文件**里面的内容**怎么改？SSH 进云电脑后，没有图形界面、没有记事本，能用的只有终端。这时候 vim（Vi IMproved）就是你的编辑器——几乎每台 Linux 都预装，无需网络、无需鼠标，配置文件、日志、脚本，全靠它在终端里完成。
>
> 初学者最常遇到的困境是"打不进去、退不出来、改不了内容"。本章就是为了打通这一关：从三种模式开始，到常用移动、编辑、查找替换，最后配置自己的 ~/.vimrc。练完本章，你能在云电脑上熟练地用 vim 做日常编辑工作。

> **本章目标**
> - 能解释 vim 的三种模式（普通模式、插入模式、命令行模式），并知道在哪个模式下做什么操作。
> - 能在云电脑上用 vim 打开文件、编辑内容、保存退出、强制退出不保存。
> - 能熟练使用 hjkl 移动光标、dd/yy/p 删除复制粘贴、u 撤销、/ 查找、:s 替换。
> - 能在 ~/.vimrc 里开启行号、语法高亮，并用 vimtutor 做官方入门练习。

---

## 7.1 为什么运维必须会 vim

服务器上编辑文件，你只有两种选择：把文件下载到本地改完再上传，或者直接在服务器上改。前者适合大体积文件，后者才是日常——修改 /etc/hostname、调一行 nginx 配置、写一个备份脚本，登上机器当场改完最快。

vim 之所以是标准配置，有三个原因：

1. **无处不在**：从 Debian 云电脑到最精简的容器镜像，几乎都预装 vim（或 vi，vim 的前身）。学会 vim 等于学会了在任何 Linux 机器上编辑文件。
2. **无需鼠标**：SSH 会话里只有键盘，vim 全程键盘操作，手离开键盘的次数越少，效率越高。
3. **轻量且稳定**：vim 启动极快，不依赖图形库，哪怕系统只剩命令行模式（救援模式），它也能用。

> **SRE 贴士**：半夜接到告警登上服务器，第一件事往往是看日志、改一行配置、重启服务。这时候你不希望去记 "nano 怎么保存" 或者 "能不能 apt install 一个图形编辑器"——vim 已经在那里了，而且十年后它还在那里。

## 7.2 vim 的三种模式

vim 最核心的设计是**模式（Mode）**：同一个按键，在不同模式下含义完全不同。这是 vim 和普通编辑器最大的区别，也是新手最容易卡壳的地方。

| 模式 | 进入方式 | 主要用途 | 提示符/状态 |
| --- | --- | --- | --- |
| 普通模式（Normal） | 启动后默认，或任何模式按 Esc | 移动光标、删除、复制、粘贴、撤销 | 底部通常不显示模式名 |
| 插入模式（Insert） | 普通模式下按 i/a/o 等 | 向文件输入文字 | 底部显示 `-- INSERT --` |
| 命令行模式（Command-line） | 普通模式下按 : | 保存、退出、查找替换、设置 | 底部显示冒号 `:` |

**关键原则**：想输入内容，先进插入模式；想执行命令（保存、退出），先按 Esc 回普通模式，再按 `:`。新手最常犯的错误是在插入模式下乱按 Esc，或者在普通模式下直接打字以为在输入。

**模式切换简图**：

```text
      Esc              i / a / o
普通模式 <----------> 插入模式
      :                       |
      v                       v
   命令行模式          (按 Esc 返回普通模式)
```

> **SRE 贴士**：vim 里按 Esc 永远不会出错——最坏情况就是"已经在普通模式了，再按一次 Esc 依然在普通模式"，伴随一声提示音或闪屏。遇到不确定当前在哪个模式时，狂按两次 Esc，回到普通模式再操作，是最稳的兜底策略。

## 7.3 打开、保存、退出

打开一个文件：

```bash
vim /etc/hostname
```

### 保存与退出（命令行模式）

在普通模式下按 `:` 进入命令行，底部出现冒号，然后敲命令并回车：

| 命令 | 含义 |
| --- | --- |
| `:w` | 写入（保存） |
| `:q` | 退出（若未保存会被拒绝） |
| `:wq` | 保存并退出 |
| `:x` | 保存并退出（仅文件有修改时才写入） |
| `:q!` | 强制退出，不保存所有修改 |
| `:wq!` | 强制保存并退出（对只读文件，若 root 有权限） |

最常用的两个组合：`:wq` 正常保存退出，`:q!` 后悔了不想保存直接跑路。

### 新建文件

```bash
vim /data/home/hello.txt
```

如果文件不存在，vim 会把它当作新文件打开，第一次 `:w` 时才真正创建。

> **警告**：vim 里 `:q!` 会丢弃**所有未保存的修改**，没有后悔药。改了一大段配置突然想放弃前半段改动，`:q!` 会连后半段好改的也一起丢掉。不确定时先 `:w` 保存个副本，再决定要不要 `:q!`。

## 7.4 光标移动（普通模式）

在普通模式下，不用方向键也能移动（方向键也能用，但 hjkl 手指不必离开主键区）：

| 按键 | 含义 |
| --- | --- |
| `h` | 左移一个字符 |
| `j` | 下移一行 |
| `k` | 上移一行 |
| `l` | 右移一个字符 |
| `w` | 向后跳到下一个单词开头 |
| `b` | 向前跳到上一个单词开头 |
| `0` | 跳到行首 |
| `$` | 跳到行尾 |
| `gg` | 跳到文件第一行 |
| `G` | 跳到文件最后一行 |
| `:n` | 跳到第 n 行（如 `:12` 跳到第 12 行） |
| `Ctrl-f` | 向前翻一页 |
| `Ctrl-b` | 向后翻一页 |

> **SRE 贴士**：日志文件往往有几千行，`G` 直接跳末尾看最新日志，`gg` 跳开头，`Shift-g` 即 G 大写，配合行号（见 7.9 节）定位错误行非常快。

## 7.5 插入、删除、复制、粘贴、撤销

### 进入插入模式

| 按键 | 含义 |
| --- | --- |
| `i` | 在光标**当前位置**前插入 |
| `a` | 在光标**当前位置**后追加（append） |
| `o` | 在当前行**下方**新建一行并插入 |
| `O` | 在当前行**上方**新建一行并插入 |
| `I` | 在行首插入（大写 i） |
| `A` | 在行尾插入（大写 a） |

插入完按 `Esc` 回普通模式。

### 常用编辑命令（普通模式）

| 命令 | 含义 |
| --- | --- |
| `x` | 删除光标所在字符 |
| `dw` | 删除从光标到单词末尾 |
| `dd` | 删除整行（剪切） |
| `yy` | 复制整行 |
| `p` | 粘贴到当前行下方 |
| `P` | 粘贴到当前行上方 |
| `u` | 撤销上一步（undo） |
| `Ctrl-r` | 重做（redo） |
| `.` | 重复上一次修改操作 |

`dd` 剪切后 `p` 粘贴，等于把当前行移到下一行；`yy` + `p` 等于复制当前行到下一行。

> **SRE 贴士**：`u` 撤销在改错配置文件时是救命稻草——不小心删了一行关键配置，按 `u` 就回来了，不用重新下载原文件。

## 7.6 可视化模式

普通模式下按 `v` 进入可视化模式，移动光标选中文本，然后：

- `d` 删除选中内容
- `y` 复制选中内容
- `~` 反转大小写

按 `V`（大写）是整行选中，按 `Ctrl-v` 是块选中（适合给多行代码同一位置加注释）。

## 7.7 查找与替换

### 查找

普通模式下：

- `/关键词`：向下查找，回车后光标跳到第一个匹配，按 `n` 继续向下，`N` 向上。
- `?关键词`：向上查找，用法同 `/`。

```text
/ERROR
```

查找到的内容会被高亮，输入 `:nohlsearch`（或 `:noh`）关闭高亮。

### 替换

命令行模式下：

| 命令 | 含义 |
| --- | --- |
| `:s/旧/新` | 替换当前行第一处 |
| `:s/旧/新/g` | 替换当前行全部 |
| `:%s/旧/新/g` | 替换**全文**全部 |
| `:%s/旧/新/gc` | 全文替换，每处询问确认（c = confirm） |

例子：把全文的 `192.168.1.10` 改成 `192.168.1.20`：

```text
:%s/192.168.1.10/192.168.1.20/g
```

> **SRE 贴士**：替换配置文件里的 IP 或域名时，先用 `:%s/旧/新/gc` 逐处确认，避免把不该改的地方（比如注释里的示例 IP）也一并改掉。

## 7.8 多文件与分屏

vim 可以一次打开多个文件、分屏编辑，适合对比两个配置文件：

```bash
vim file1 file2           # 打开两个文件，:n 下一个，:N 上一个
:split file2              # 横向分屏打开 file2
:vsplit file2             # 纵向分屏打开 file2
Ctrl-w w                  # 在窗口间切换
Ctrl-w q                  # 关闭当前窗口
```

日常编辑单个配置文件时用不到，但知道有这个能力即可，深入用法见 vim 自带帮助。

## 7.9 配置 ~/.vimrc

vim 默认不显示行号、没有语法高亮，长期使用建议写个 `~/.vimrc`（vim 配置文件，放在家目录）：

```text
set number          " 显示行号
set relativenumber  " 相对行号（可选，便于跳行）
syntax on           " 语法高亮
set tabstop=4       " Tab 宽度 4 格
set shiftwidth=4    " 自动缩进 4 格
set expandtab       " Tab 键插入空格而非制表符
set ignorecase      " 查找忽略大小写
set smartcase       " 含大写时区分大小写
set hlsearch        " 高亮查找结果
set cursorline      " 高亮当前行
```

双引号 `"` 是 vim 配置文件里的注释符号。保存后下次打开 vim 即生效。

> **SRE 贴士**：把自己的 `~/.vimrc` 当成运维工具箱的一部分。换一台新云电脑、新服务器，先传上去这份配置，编辑体验立刻和以前一致——这也是"基础设施即代码"思想在个人工具上的微型实践。

## 7.10 vimtutor 与"退不出来"急救

vim 自带交互式教程 `vimtutor`，大约 30 分钟走完，涵盖本章所有核心操作，是学 vim 的最佳起点：

```bash
vimtutor
```

如果在 vim 里彻底卡住了，不知道怎么退：

1. 按 `Esc` 回普通模式（连按两次更稳）。
2. 输入 `:q!` 回车，强制退出不保存。
3. 实在退不出，挂起当前终端（`Ctrl-z`）或直接关终端重新 SSH，文件不会因此损坏（vim 有 swap 文件保护，下次打开会提示恢复）。

> **警告**：不要在 vim 里编辑大型二进制文件（如已编译的二进制程序、数据库文件），vim 是文本编辑器，打开二进制文件可能损坏文件内容。只编辑文本配置、脚本、日志。

## 本章小结

| 知识点 | 核心要点 |
| --- | --- |
| 三种模式 | 普通=移动/编辑命令，插入=输入文字，命令行=保存退出查找替换 |
| 模式切换 | Esc 回普通模式，i/a/o 进插入模式，: 进命令行模式 |
| 保存退出 | `:w` 保存，`:q` 退出，`:wq` 保存退出，`:q!` 强制退出不保存 |
| 光标移动 | hjkl 单字符，w/b 单词，0/$ 行首行尾，gg/G 首尾行，:n 第 n 行 |
| 编辑命令 | x 删字符，dd 删行，yy 复制行，p 粘贴，u 撤销，Ctrl-r 重做，. 重复 |
| 查找替换 | / 和 ? 查找，n/N 继续，:%s/旧/新/g 全文替换 |
| 配置 | ~/.vimrc 里写 set number / syntax on 等，永久生效 |
| 入门教程 | `vimtutor` 官方 30 分钟交互式教程 |

本章解决了"在终端里改文件"的问题。下一章（第 8 章《进程管理与系统监控》）我们转向正在运行的程序：怎么看到进程、怎么判断系统忙不忙、怎么控制进程。

## 动手练习

在自己的云电脑上完成以下练习。

**练习 1**：用 `vim /tmp/vim-test.txt` 新建文件，进入插入模式输入三行任意文本，按 `Esc`，用 `:wq` 保存退出；再用 `cat` 查看文件内容是否正确。

**练习 2**：重新打开 `/tmp/vim-test.txt`，用 `dd` 删除第二行，用 `u` 撤销，再用 `yy` 复制第一行、用 `p` 粘贴到末尾，最后 `:wq` 保存。

**练习 3**：在文件里用 `/` 查找某个单词，按 `n` 跳到下一个匹配，用 `:nohl` 关闭高亮。

**练习 4**：用 `:%s/旧文本/新文本/g` 把文件里某个词全部替换，每处都用 `gc` 版本逐行确认一次。

**练习 5**：在家目录创建 `~/.vimrc`，写入 `set number` 和 `syntax on`，再打开任意文本文件确认行号和语法高亮生效。

## 参考答案

**答案 1**：

```bash
vim /tmp/vim-test.txt
# (按 i 进入插入模式，输入三行文本)
# (按 Esc 回普通模式)
:wq
cat /tmp/vim-test.txt
```

预期输出：你输入的三行文本原样显示。

**答案 2**：

```bash
vim /tmp/vim-test.txt
# (光标移到第二行，按 dd 删除)
# (按 u 撤销，第二行恢复)
# (光标移到第一行，按 yy 复制)
# (按 G 跳到最后，按 p 粘贴)
:wq
```

关键点：`dd` 删除的是整行，`u` 能撤销最近一次修改，`yy`+`p` 是复制整行并粘贴到当前行下方。

**答案 3**：

```text
/要查找的单词   # 回车后跳到第一个匹配
n               # 跳到下一个匹配
:N              # 跳回上一个匹配
:nohl           # 关闭高亮
```

**答案 4**：

```text
:%s/旧文本/新文本/gc
# 每处出现时 vim 会提示 replace with 新文本 (y/n/a/q/l/^E/^Y)?
# 按 y 替换，n 跳过，a 全部替换并继续，q 退出替换
```

**答案 5**：

```bash
vim ~/.vimrc
# (按 i 进入插入模式，输入)
set number
syntax on
# (按 Esc，:wq 保存退出)
vim /etc/hostname   # 应看到行号和语法高亮
```

注意：语法高亮在无内容或纯文本时不明显，用带扩展名的文件（如 `.sh`、`.conf`）更容易看出高亮效果。
