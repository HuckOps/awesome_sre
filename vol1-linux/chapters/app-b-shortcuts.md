# 附录 B 常用快捷键与 vim 技巧

> 命令是背不完的，但高频键位屈指可数。这份附录把全书用到的快捷键收成六张表：bash 行编辑、less 翻页、tmux 会话、vim 按键、SSH 终端的复制粘贴，外加 nano 的一句话上手。同样，这是词典不是考纲——忘了来翻，用顺手了自然就不用翻了。vim 部分和 tmux 前缀约定与正文完全一致：vim 全量讲解在第 7 章《vim 编辑器》，tmux 在第 8 章《进程管理与系统监控》。

## B.1 bash 快捷键

在提示符下编辑命令行的一套家法，出自 readline 库，bash 里通用。记十二条顶得上每天少敲两百次退格键。

| 按键 | 作用 |
| --- | --- |
| `Ctrl-A` | 光标跳到行首 |
| `Ctrl-E` | 光标跳到行尾（End） |
| `Ctrl-U` | 删掉光标到行首的全部内容 |
| `Ctrl-W` | 删掉光标前的一个单词 |
| `Ctrl-K` | 删掉光标到行尾的全部内容 |
| `Ctrl-L` | 清屏，光标回到左上角（等价 `clear`） |
| `Ctrl-R` | 在历史命令里增量搜索，输入即匹配；再按 `Ctrl-R` 继续上一条，回车执行，`Ctrl-G` 放弃 |
| `Ctrl-C` | 中断当前前台命令（在终端里它**不是**复制） |
| `Ctrl-D` | 发送 EOF：行首处退出当前 shell，光标处向后删字符 |
| `Ctrl-Z` | 把前台任务挂起到后台，用 `fg` 找回 |
| `Tab` | 补全命令、路径、参数；连按两下列出所有候选 |
| `↑` / `↓` | 翻上一条 / 下一条历史命令 |

> **SRE 贴士**：终端被 `cat` 了一个大文件搞到花屏、错行时，敲一条 `reset` 回车，屏幕立刻恢复理智——比关窗重连快得多（第 4 章《文件与目录操作》留的锦囊）。另外 `Ctrl-S` 是冻结终端输出（流控老规矩），误按了屏幕不动不是死了，`Ctrl-Q` 解救。

## B.2 less 分页器快捷键

`less` 是 `man` 的底层，也是看大文件的正确姿势：进去之后下面这些键够你用。

| 按键 | 作用 |
| --- | --- |
| 空格 / `f` | 向下翻一页 |
| `b` | 向上翻一页 |
| `/关键字` | 向下查找，回车确认 |
| `n` / `N` | 跳到下一个 / 上一个命中 |
| `g` 或 `1G` | 跳到开头 |
| `G` | 跳到结尾 |
| `q` | 退出 |

## B.3 tmux：前缀 Ctrl-b 约定

先把约定说死：**tmux 里所有快捷键都是「先按 Ctrl-b，松开，再按下一个键」**，不是三键同按。前缀按住不放连按是没反应的。

| 按键 | 作用 |
| --- | --- |
| `Ctrl-b d` | 脱离会话（detach），任务在后台继续跑 |
| `Ctrl-b c` | 新建窗口（create） |
| `Ctrl-b n` / `Ctrl-b p` | 下一个 / 上一个窗口 |
| `Ctrl-b 0`~`9` | 按编号直接跳窗口 |
| `Ctrl-b &` | 关闭当前窗口（有确认提示） |
| `Ctrl-b "` | 横向切窗格 |
| `Ctrl-b %` | 纵向切窗格 |
| `Ctrl-b 方向键` | 在窗格之间移动焦点 |
| `Ctrl-b z` | 当前窗格最大化 / 还原 |
| `Ctrl-b [` | 进入复制模式，可用方向键翻看历史输出，`q` 退出 |

会话级的操作（`tmux new -s work`、`tmux attach -t work`、`tmux ls`、`tmux kill-session -t work`）是敲命令不是按快捷键，详见第 8 章《进程管理与系统监控》。

## B.4 vim 速查表

vim 的家法是「模式」：普通模式下按 `i` 才进插入，改完按 `Esc` 回来。全表按模式分组，忘了自己属于哪就从第一行开始念。

| 分组 | 按键 | 作用 |
| --- | --- | --- |
| 模式切换 | `i` / `a` / `o` | 在光标前 / 后 / 下一行插入 |
| 模式切换 | `Esc` | 回到普通模式，改错了先按它 |
| 模式切换 | `v` / `V` / `Ctrl-v` | 可视 / 行可视 / 块可视模式 |
| 模式切换 | `:` | 命令行模式，存盘、退出、替换都从这开始 |
| 移动 | `h` `j` `k` `l` | 左、下、上、右（练成肌肉记忆前别看方向键） |
| 移动 | `w` / `b` | 下一个 / 上一个单词 |
| 移动 | `0` / `^` / `$` | 行首 / 首个非空字符 / 行尾 |
| 移动 | `gg` / `G` / `12gg` | 文件头 / 文件尾 / 第 12 行 |
| 移动 | `Ctrl-d` / `Ctrl-u` | 向下 / 向上翻半屏 |
| 移动 | `Ctrl-f` / `Ctrl-b` | 向下 / 向上翻整屏 |
| 移动 | `H` / `M` / `L` | 跳到屏幕顶 / 中 / 底 |
| 移动 | `{` / `}` | 上一段 / 下一段（按空行分段） |
| 编辑 | `x` / `dd` / `dw` | 删字符 / 删整行 / 删一个单词 |
| 编辑 | `cc` / `cw` | 改整行 / 改一个词（删掉并进插入模式） |
| 编辑 | `I` / `A` | 在行首 / 行尾进入插入 |
| 编辑 | `o` / `O` | 下方 / 上方新开一行并插入 |
| 编辑 | `yy` / `3yy` / `p` / `P` | 复制一行 / 三行 / 粘贴到光标后 / 前 |
| 编辑 | `u` / `Ctrl-r` | 撤销 / 重做 |
| 编辑 | `J` | 把下一行合并到本行行尾 |
| 编辑 | `>>` / `<<` | 整行右缩进 / 左缩进 |
| 编辑 | `.` | 重复上一次修改（vim 的杀手锏） |
| 查找替换 | `/词` / `?词` | 向下 / 向上查找 |
| 查找替换 | `n` / `N` | 下一个 / 上一个命中 |
| 查找替换 | `*` / `#` | 直接搜光标下的单词，向下 / 向上 |
| 查找替换 | `:%s/old/new/g` | 全文替换；加 `c` 变成逐个确认（`:%s/old/new/gc`） |
| 查找替换 | `:1,10s/old/new/g` | 只替第 1 到 10 行 |
| 查找替换 | `:set paste` | 粘贴代码前开启，避免自动缩进把格式搞乱；粘完 `:set nopaste` |
| 可视 | `v` 后 `d` / `y` | 选中后删除 / 复制 |
| 可视 | `Ctrl-v` 块选 + `I` | 竖着选一块，`I` 在每行行首批量插入，`Esc` 确认——多行加注释的经典姿势 |
| 多窗口 | `:sp` / `:vsp` | 上下 / 左右分窗，都可带文件名（`:sp other.txt`） |
| 多窗口 | `Ctrl-w` + `h/j/k/l` | 切到左 / 下 / 上 / 右窗口 |
| 多窗口 | `Ctrl-w` + `w` | 在所有窗口间循环切换 |
| 多窗口 | `:tabnew` / `:tabn` | 新标签页 / 切下一个标签页 |
| 多窗口 | `:q` | 关闭当前窗口（最后一个窗口时就是退出） |
| 保存退出 | `:w` / `:q` / `:wq` | 保存 / 退出 / 保存并退出 |
| 保存退出 | `:q!` | 不保存，强退（改崩了时的救命键） |
| 保存退出 | `ZZ` | 等价 `:wq`（有修改才存） |
| 保存退出 | `:wqa` | 所有窗口全部保存并退出 |
| 保存退出 | `:!命令` | 临时执行外部命令，如 `:!ls -l` |
| 保存退出 | `:r !命令` | 把命令输出插进光标处，如 `:r !date` |

> **SRE 贴士**：SSH 会话里粘贴一大段配置，缩进一夜回到解放前？九成是没开 `:set paste`——它让 vim 暂时收起自动缩进和自动补全，原样接收粘贴内容。同理，`vim` 打开带 BOM 或 CRLF 的 Windows 文件满屏 `^M`，`:set ff=unix` 一救了结。

## B.5 SSH 终端里的复制粘贴

SSH 终端是个「终端冒充者」：`Ctrl-C`/`Ctrl-V` 在这就是中断和「没什么用」，复制粘贴必须加 Shift（详见第 2 章《首次登录：SSH、终端与第一组命令》）。

| 操作 | 按键 | 说明 |
| --- | --- | --- |
| 复制 | `Ctrl-Shift-C` | 先用鼠标左键划选目标文本，再按组合键 |
| 粘贴 | `Ctrl-Shift-V` | 在提示符处按下，粘贴剪贴板内容 |
| 选中即复制 | 鼠标划选 | 多数 Linux 桌面终端支持；单击鼠标中键（滚轮键）粘贴 |
| tmux 里划选 | 按住 `Shift` 再划选 | 绕过 tmux 的鼠标捕获，直接用终端自身的选择 |
| macOS 用户 | `Cmd-C` / `Cmd-V` | Terminal/iTerm 需勾选「将选中的文本复制到剪贴板」类选项 |
| 警惕 | 中文引号 | 从网页复制的命令可能带中文引号，粘进去必报错；本书命令建议照着手敲两遍 |

## B.6 nano：一句话

Debian 默认就带 `nano`（服务器上还可能遇到 `vim.tiny`），救急够用：`Ctrl-O` 保存（会问文件名，回车确认），`Ctrl-X` 退出（未保存会问是否保存，按 `Y` 确认）。它在界面底部直接摆着一排快捷键提示，认字就会用。但排版、批量改、多窗口这些活还是 vim 顺手，第七章值得认真过一遍。

## B.7 vim 进阶一句流与 vimtutor 建议

最后送你七句「一句流」，每句都是一个能立刻用上的小绝招：

1. `.` 重复上次修改：改完一处缩进，光标移到下一处按 `.` 就行，别重敲一遍。
2. `q:` 和 `q/`：命令行历史和搜索历史以窗口形式打开，翻旧命令比按一百次 `↑` 快。
3. `ma` 在当前位置设标记 a，`'a` 跳回来——两个文件位置间来回改的救命键。
4. `:argdo %s/old/new/g | update`：`:argadd` 收一批文件后，一条命令批量替换过去。
5. `Ctrl-v` 块选加 `I`，给一百行同时加注释前缀；`x` 再集体删掉——注释墙的推倒与重建。
6. `:set number relativenumber` 显示相对行号，配合 `5j`、`3k` 心里有数；`:%s/\s\+$//` 一行清掉全文行尾空格。
7. `vimtutor`：系统自带的交互教程，一条命令进入，约三十分钟跟一遍——上表的键位只是索引，手感全靠它练出来。真想定制，`.vimrc` 写起（`syntax on`、`set number`、`expandtab`、`mouse=a`），详见第 7 章《vim 编辑器》。
